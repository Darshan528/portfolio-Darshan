# Why VLSI

Right now I mostly write software, Java and Python, and that's still what I use most days. But the thing I keep coming back to is wanting to know how something works all the way down. Software always has another layer under it, another library, another runtime someone else built. Eventually it just calls something else. Hardware doesn't have that out, it's the layer everything else stands on.

This year I started a Verilog course through UC San Diego, and it's the first time I've actually designed digital logic instead of writing code that just runs on top of a chip someone else made. That's the direction I want to go: VLSI. Designing the silicon itself, not just the software running on it.

Right now that means Verilog and digital logic fundamentals. Longer term it means becoming a VLSI Hardware Engineer, building the chips instead of the code that sits on top of them.
